# 无痕窗口专用翻译服务与模型

基于独立的无痕翻译缓存隔离补丁，新增一个默认关闭的服务/模型配置。仅修改请求级配置，不在窗口切换时修改全局偏好，不另建完整配置系统，不新增浏览器权限。

## 行为

- 通用设置 → 功能服务分配，配置无痕专用供应商和模型。选择服务时复制其当前模型作为初值，之后与普通模型独立保存。
- 专用模型优先于普通高级请求体的 model 字段；只移除此字段，保留其余高级参数。
- Popup、文档与写作卡片的前置检查使用专用配置，不被普通服务缺少凭据错误阻断。
- 私密圈选的能力探测保持私密请求标记，仅用独立内存缓存；不写普通探测存储或用量。
- 未启用时沿用既有服务选择。启用但未配置、供应商已删除、本地模型 ID 无效或凭据/推理失败时停止，不回退普通供应商。
- 排除多供应商自动回退的“免费翻译”聚合服务；可以选择一个明确的免费机器翻译服务、本地模型或用户配置的云端模型。
- 普通配置生成的批量请求在专用服务仅接受单条输入时，复用已有单条管线逐条处理，共享原有总 deadline；不把数组错误地发给本地模型。
- 普通窗口与无痕窗口同时存在时，由真实发送者确定来源；任意网页 JSON 的 incognito 字段不生效。
- 输入框、圈选、图片 Offscreen OCR、阅读和写作各自入口也使用专用配置。圈选/图片事务的服务、模型和 provider 快照在等待前冻结；中途修改设置不会把已捕获的内容改发给另一个供应商。
- 翻译中心在专用配置开启时暂停多供应商对比并显示说明，避免把同一专用模型的结果错误标为其他供应商；保留原服务列表。
- Popup 在无痕页面显示实际专用服务/模型，并说明服务菜单继续编辑普通偏好。
- 配置字段、UI 文案和七种界面语言随现有保存机制持久化。关闭再开启保留专用选择。

## 边界

专用设置只在支持的浏览器扩展构建中展示；用户脚本和 Thunderbird 不展示此功能。

这不是“完整匿名模式”。远程模型仍会收到内容，并复用已配置地址和凭据；词典、TTS 和音视频识别/转录缓存保持各自设置。不会自动允许扩展访问无痕窗口。

普通翻译协议覆盖全文、悬浮、划词、字幕等内容脚本路径。支持的扩展文档页同样按 sender.tab 处理，但 Chrome 默认 spanning 模式不能在无痕主框架打开 document.html；本补丁没有改成 split，也没有宣称解除该平台限制。Firefox 不支持 split。

## 验证

- 私密/普通并发、相同供应商/模型去重、错误配置拒绝且零 provider 调用、关闭后保持普通服务、正常配置不变
- 未知本地模型拒绝，不能被旧 normalizeLocalTranslationModel 静默替换为默认模型
- 冻结 provider 配置后的专用模型修改，及真实图片 OCR → Offscreen → broker 延迟期间修改配置
- 输入框服务和模型覆盖、阅读/写作模型与用量隔离
- Vue 模板实际编译并 SSR 渲染，检查默认关闭、权限提示、云端边界、供应商删除后的可见错误；Element Plus 控件为测试适配器，不冒充真实浏览器键盘/布局验证
- 两个新纯模块 privateTranslation.ts、privateContext.ts 的 statements/branches/functions/lines 均为 100%

实际消融：撤掉 broker 专用路由，14 项中 8 项失败；撤掉 profile 快照复制/冻结，1 项失败；撤掉本地模型严格校验，1 项失败。新增单条服务适配用例后，撤掉批量适配会另有 1 项失败。恢复后通过。新增高级 model 优先级、Popup 预检、探测标记及对比门控消融各触发 1 项回归失败。未新增模型探测请求、通用配置子系统或全局窗口监听器。

真实 Chrome/Firefox 隐私窗口交互和布局仍待环境允许后验证。类型/构建验证单独记录；不能把 mock 测试当成真实云端或本地模型质量证明。
