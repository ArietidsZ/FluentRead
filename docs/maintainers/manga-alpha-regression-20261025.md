# 漫画透明图片修补回归（2026-10-25）

本轮处理透明图片中的原字残留、透明补丁重复叠加及半透明底色误铺成不透明色块。修复与验证按各自边界记录；本文不表示本轮候选已经合入或发布，也不表示全部图片载体、OCR、分段或透明度问题已经解决。

## 三个根因与修复边界

1. **RGB 修补保留了原字的 alpha。** LaMa 输出三个 RGB 通道，不预测 alpha；旧回写改变颜色，却保留 source-over 字形增加的透明度。`src/features/image-translation/services/mangaInpainting.ts` 现在仅在已有补丁采样发现非255透明度时，检查每个既有文字蒙版完整一像素外周。外周 alpha 完全一致且不触图边时，才在原蒙版内应用 `min(原alpha, 外周alpha)`。此回写步骤不填平更低的0、96等 alpha，但不约束后续铺底或译文字形覆盖。边界不一致、触边或无法证明时保留原 alpha；不扩大蒙版，不猜测缺失文字。
2. **最终 RGBA 补丁又叠在原像素上。** 完整补丁已经包含蒙版外的原像素，继续 source-over 会叠加原画和字形。`src/features/image-translation/content/mangaCompositor.ts` 先清除该补丁的有效矩形，再绘制完整最终补丁。相同半透明像素重复叠加时，alpha24可变为46、150可变为212；矩形替换避免这一次额外叠加。既有尺寸校验、超时、取消、迟到位图关闭和失败释放继续保留。
3. **RGB 均匀不等于背景不透明。** 旧背景分类允许 alpha>=128 的相近 RGB 进入均匀背景路径，随后不透明 `fillRect` 会覆盖半透明源图。`src/features/image-translation/services/mangaRendering.ts` 现在要求全部既有边缘采样点的 alpha 均为255，才允许沿用原来的 RGB±20和九成匹配规则。任一已采样点有透明度即退出该快速分类；这不是整框所有像素均不透明的证明。

alpha 外周检查使用原始像素，复杂度是既有蒙版周长之和，即 O(Σ perimeter)，只增加一个可选 alpha 标量；不新增整页扫描、像素数组或 Canvas 回读。不透明补丁沿用已有采样循环并跳过外周检查。重叠蒙版的内部外周也必须一致，因此可能保守地放弃修复。既有缩放采样仍可能漏掉极薄的透明像素。

该规则仅在既定准入下把高于外周的 alpha 压低；不证明内部高 alpha 都来自 source-over 字形。蒙版内原有的不透明图案也可能被压低，RGB本就由模型改写。它不能修复通过降低 alpha 形成的镂空字，不能预测非均匀 alpha，也不能证明蒙版内任意背景 RGBA 已精确恢复。渲染分类变严格后，原先误入均匀路径的区域可能进入既有 LaMa 修补流程，因此不能宣称整页模型调用数量或耗时必然减少。

## 透明载体的显示与恢复

本轮 IMG 路径已有原图显示隔离：译图挂载后才隐藏原图，恢复时归还显示状态。简单原生 Canvas 现在也在来源复核、译层挂载和可见性检查通过后，借用 `opacity:0!important` 与 `transition-property:none!important` 隐藏原绘制层。暂停、失效、离屏、遮挡、失败和释放时归还；无宿主 inline 改写时精确恢复原 style 属性文本，宿主改写时只按所有权归还借用的两项属性，不覆盖新的 duration 等声明。源像素和翻页交互保持原路径。

该 Canvas 交接只用于透明 CSS 底色、没有额外边框、内边距、阴影、滤镜、遮罩或几何变换等的简单绘制；祖先 opacity 必须为1，活动动画或无法检查动画时不借用。复杂样式仍保留既有叠层行为，不能据此称复杂 CSS 的透明残字已修复。仅更改样式表、保持相同 class/inline 的底层 opacity 规则，会被借用的 inline opacity 遮蔽；本轮不通过逐帧撤样式、强制重排或全页 observer 探测这类变化。

单层同源 blob 背景正文改在原元素的背景层显示完整译图：先将合成画布异步编码为 PNG，并用原生 Image 完成尺寸和可加载检查，再借用唯一的 `background-image` 长属性。背景色、子内容、按钮、裁切、滤镜及浏览器自身的绘制顺序继续由原元素负责；不把整个元素设为透明，也不再用页面顶层画布遮住子内容。未完成、失败或取消时保留原背景，不能以空译图替换原图。

背景显示资源在暂停、遮挡及离屏时归还原样式并保留，以便缓存返显；来源变化、永久释放和卸载时归还并撤销自有 blob URL。没有宿主写入时精确恢复原 style 文本；宿主修改其他声明时只归还自有背景图。宿主仅把同一译图 URL 的优先级改为普通时，归还原来源并保留新的优先级，避免留下已撤销的译图 URL。识别身份继续指向原来源，不能把扩展自己的输出当作新漫画页。

该路径保留已有单层 `contain`、`no-repeat`、`padding-box`、无边框内距及尺寸准入。每次新合成增加一次 PNG 编码和原生 Image 预加载，压缩 blob 与浏览器解码有实际内存成本；完整合成画布在资源准备好后释放，暂停返显复用同一资源，不重新编码或运行模型。预加载不保证未来 CSP 或 CSS 加载条件不变，也不保证浏览器绝不会再次解码，不能据此宣称零分配或整页提速。保持相同 class 和 inline、只修改底层样式表的背景来源，可能被借用的 inline 声明遮蔽；本轮不加全页 observer 或逐帧撤样式探测。

长图分段仍可能在透明译图下面保留原始绘制层，露出原字或再次叠加半透明颜色。修复结果画布内部的补丁替换，不等于处理了另一个 DOM 原图下层。

不能直接把整个长图 IMG 设为透明，这会连未完成、失败的其他分段一起隐藏。分段仍需独立的显示所有权、可见性判断、取消和恢复流程；本轮没有据此宣称全部 surface 通过。Canvas 的样式交接复用已有布局检查，不增加像素回读、模型推理或整页像素数组；额外 CSS/动画检查仍有成本，未测端到端提速。

## 六个新增结构与首次真实基线

六景包含透明英日双气泡与桥梁插画、半透明通知跨纹理市场背景、文字框内的 alpha 孔洞、同色面板独立标签、反色相邻气泡，以及带窄分隔线、嵌卡和书脊的双栏地图。它们不是把旧图换几句字后作为新样本；所有完整原文、段落组、负区和保护点都在首次 OCR 前确定，失败后不重写。

首轮使用先前冻结的 V8 生产构建 `0c58cb656be810441a6db3c4a35bd8d41b1bea35`，十个固定图片模块与本轮基线一致。真实识别结果是 **26/29 anchors、0/6 strict scenes**；分组失败等仍全部计入：

- 孔洞页把两处孔洞边缘额外认成 `I`，不是合法原文，不能追加进 expected source。
- 地图书脊的 `INDEX 09` 被识别为 `N D EX 0 0`，实际源框为 x746–844、y148–1024，字高876，远大于真实书脊文字。
- 该错误大框使保护点800,1010从 RGB60/56/50变成245/240/217。运行因此在保护断言失败，未生成最终质量汇总，也未完成地图页的恢复/缓存返显检查。

这是一组实际暴露问题的固定回归输入，不能把44个 corpus 单测通过称为六景 OCR 或透明修补全部通过。新候选仍在同一保护点失败时，也必须保留失败，而不是移走保护点、放宽框或删去书脊文字。

alpha 验收还有明确缺口：通知页的白色半透明层已经与不透明市场底合成，内部最终 alpha 是255；同色控制面板也是不透明对照。透明双气泡页的四个既定 alpha probes 都落在透明区，没有直接采样208/224的气泡内部。孔洞页的0/96 probes 位于完整源文字框内、字间空白处，不切任何字形；实际基线和候选输出在两点都变为255，且都进入新译文边界框，无法据此区分修补、铺底和新文字覆盖，不能宣称最终孔洞保留。

目前 runner 只消费原有 RGB 保护字段，未校验新增 `protectedAlphaProbes` 和 `sourceAlphaHoles`。离线读取实际 PNG 时，25点中23点的 alpha 与源一致、原始 RGBA 为21点，基线和候选相同；另两处地图 RGB 相差1且 alpha 不变，须区分 Canvas 预乘往返量化。以上是逐点观察，不是质量分数。完整源 RGBA 散列和 Pillow 源像素证据不等于译图 alpha 校验；应另检查实际 patch、译文字形覆盖、译图 RGBA 及恢复行为，不能用 anchors、源 probe 数量或原图未修改代替，也不把含意图译文字形的全图 alpha 变化量减少当成效果提升。

## 已完成的有限验收与性能计量

新构建在两个旧透明场景的独立真实 smoke 中通过6/6 anchors、2/2 strict scenes，两个负区零误报；全部恢复原文和缓存返显成功，追加 OCR/文字请求均为0。页面、后台及 offscreen/Worker 诊断整体通过，但保留一个 unique、两个 raw 的上游 ORT placement warning：只有来源及脚本归属明确、功能实际通过时才归为 advisory，不能写成全部 warning 为0。该结果不扩大为六新景、全部51景或全部载体通过。

实际 PNG 的有限像素对照先逐字节重建八张源图，并核对35个字形 alpha 散列。只选字形 alpha>=128、相对写字前底图 alpha 提高至少8、处于前后既有清字蒙版内，且在两边实际 `fillText` 裁剪框外再留1px的源字像素。旧红/青两景共403+1420=1823点，旧输出全部偏离底图 alpha，候选在这些点均恢复到底图 alpha且没有增加；新双气泡只剩2点可独立测量，残差2→0。大部分原字落在被排除的译文裁剪框内，不能据此判断；地图仍有36/73点残差，反色页另有42个非字形点 alpha 残差，RGB背景也不精确。因此不宣称全部源字清完、恢复精确 RGB或保留孔洞。旧两景在八景运行与独立 smoke 的 PNG、texts、ocrLines及实际绘制记录均完全相同，但八景运行仍因地图保护点失败，不能称整组通过。
