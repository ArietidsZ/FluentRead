# 设置

打开 FluentRead 弹窗，点击设置图标即可进入完整设置。大多数选择会自动保存，不需要登录账号。

## 先调整这几项

- **默认目标语言**：选择网页、划词和悬浮翻译要使用的语言。
- **默认翻译服务**：选择网页翻译默认使用的服务。
- **翻译模式**：选择保留原文的双语对照，或只显示译文。
- **译文样式**：调整颜色、字号和译文显示方式。
- **界面主题**：选择跟随系统、亮色或暗色主题。
- **界面与弹窗**：在通用设置中从 10 套皮肤里选择喜欢的布局与配色，并按需隐藏 Popup 中的快捷功能栏、当前网站栏目或底部信息栏。

皮肤分为“效率与可读性”和“氛围配色”两组：前者包含默认、简约、紧凑和高对比，后者包含奶酪、海盐、抹茶、樱花、夜幕和纸张护眼。风格只改变扩展 Popup 和设置页的呈现，不会关闭翻译功能；隐藏栏目也只是移除入口，相关功能仍可在对应设置中调整。除完整默认布局外，其余皮肤以及隐藏任一栏目后的 Popup 都会按实际内容收缩高度，不保留多余空白。

## 让网站按你的习惯工作

在“网站规则”中可以：

- 让常用网站打开后自动翻译；
- 对某个网站暂时或长期关闭 FluentRead；
- 管理已经保存的网站名单。

规则按网站保存，不会影响其他网站。

## 更多功能

“翻译设置”可以调整悬浮、划词、输入框和全文翻译；“图片与圈选翻译”管理图片文字识别；“视频字幕翻译”管理 YouTube 字幕；“备份与恢复”用于迁移或找回 FluentRead 数据。

如果只是想连接一个翻译服务，请继续阅读[翻译服务](/config/translation-engines)。
