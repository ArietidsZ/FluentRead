# 译文外观与阅读辅助

让原文与译文容易区分，也让每次阅读更舒适。

## 译文样式

在 **设置 → 界面风格 → 译文样式** 中选择双语对照时译文的显示效果。样式按 **文字、线条、标记、卡片** 分类，每张卡片直接展示实际效果；旁边的预览模拟一段网页，可以切换 **浅色网页** 和 **深色网页**，检查译文在不同配色的网站上是否清楚。

**自定义外观** 可以进一步调整：

- **译文颜色**：为译文单独指定文字颜色，选择“默认”则跟随网页。
- **译文背景色**：给普通译文或任何内置样式设置独立背景；选择“默认”则保留该样式原有背景。
- **线条颜色**：修改下划线、波浪线、边框和引用色条的颜色。
- **标记底色**：修改荧光标记、学习标记、底色和卡片的颜色，并按样式自动调整深浅。
- **字号、不透明度、字重和字体**：用滑块或直接输入 50%–250% 的字号，相对原文放大或缩小译文，或让译文更醒目、更柔和。

每种颜色都提供精选色板和取色器，也可直接输入 CSS 颜色名称、`rgb(红, 绿, 蓝)` 或十六进制色值；无效输入不会保存。点“恢复默认”回到样式自带的外观。颜色、字号等外观调整会立即应用到已打开网页上的译文，无需重新翻译；切换样式后，下一次翻译开始使用新样式。仅译文模式不使用这些样式，页面会提示并提供切换到双语对照的按钮。

也可以在 **直接输入 CSS 样式** 中写译文的声明，例如 `color: rebeccapurple; background: rgb(255, 248, 204); font-size: 117%;`。无需写选择器；只接受颜色、字体、边框等外观属性，网址、选择器和定位属性会被忽略。有效声明会覆盖上方控件的对应值，并立即显示在当前预览中。保存为命名样式后，样式卡片也会显示自己的真实效果。

“模糊遮罩”会先模糊显示译文，指针移到译文上再看清，适合先读原文、再核对自己的理解。

## 双语逐句高亮

在 **设置 → 翻译设置 → 阅读辅助** 中开启 **双语逐句高亮** 后，将光标移到原文或译文中的一句话上，即可同时高亮两侧对应的句子。无需点击或按快捷键，适合在长段落中定位难句、核对翻译偏差。旁边的译文样式预览提供多句对照，可以直接试用。

原文和译文句数一致时按顺序对应；服务拆句或合句时，根据句序和相对长度组成相邻句组。这是本地近似对齐，不能判断翻译是否正确，改写幅度较大或调整语序的译文可能无法准确对应。高亮不增加翻译请求，也不改变网页文字和排版。

仅双语模式生效。恢复原文、关闭开关或离开文字后清除高亮；拖选文字时让位给网页选区。需要浏览器支持 CSS Custom Highlight API，旧版浏览器缺少该能力时保留正常翻译。
