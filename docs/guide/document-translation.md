# 文档翻译

文档翻译支持导入本地文件、双语对照阅读、校订译文和下载结果。

<GuideVisual kind="document" />

## 打开文件

从扩展菜单进入 **文档翻译**，将文件拖入页面，或点击选择文件。

在线 PDF（例如 [Attention Is All You Need](https://arxiv.org/pdf/1706.03762)）可以直接打开扩展菜单，点击 **打开 PDF 阅读器** 或 **文档翻译**。也可以在文档首页粘贴 PDF 链接。浏览器自带 PDF 查看器限制内容脚本，FluentRead 会在自己的阅读页打开原文件，不修改原文。需要登录的下载地址若无法打开，请先下载再导入。

支持 PDF、ePub、Word（DOCX）、HTML、TXT、Markdown、JSON，以及 SRT、VTT、ASS、SSA、LRC 字幕文件。旧版 `.doc` 文件请先另存为 `.docx`。

还没有文件时，可展开 **没有文件？先用范例试试**，打开文章、字幕或语言文件范例。范例在本地导入，不会自动开始翻译；确认设置后可使用与真实文件相同的阅读、校订和下载流程。

## 翻译与对照阅读

1. 在文档上方确认语言与服务，点击 **调整设置** 选择源语言、目标语言、服务和 AI 模型。设置按需打开，为正文保留完整阅读区域。
2. 检查文件内容，点击 **开始翻译**。
3. 通过 **原文 / 双语 / 译文** 切换阅读方式。

较长的文档可以暂停。暂停或请求失败后，已完成的内容会保留，继续翻译时处理剩余部分。更换语言、服务、模型或术语设置后，需要按新设置重新翻译，页面会先提示。

翻译完成后，主区域保留阅读、校订和下载。需要重新翻译、管理服务连接或更换文件时，从 **调整设置** 进入；现有未下载结果会受到确认提示保护。

Markdown 围栏代码块保持原文，包括引用和列表中的围栏；阅读预览会将它们作为代码展示。JSON 保留原有结构和非文本值，嵌套超过 1000 层时会提示无法处理。

## 校订与下载

点击 **校订译文**，搜索想修改的句子，或筛选尚未翻译的片段，直接编辑译文。修改会用于预览和下载。

点击 **下载文件**，下载方式默认跟随当前的双语或译文阅读方式；阅读原文时保留上次下载选择。可在弹窗中再次选择双语或仅译文，核对输出文件名和内容预览。二进制文件展示文字摘录，实际下载仍保留原格式。

ePub、DOCX 和批量 ZIP 下载会显示打包百分比，可以取消后再次下载，译文和校订会保留。大型 JSON 的下载预览使用文字摘录，实际文件仍包含完整 JSON 结构；文本格式只生成弹窗需要的预览片段。PDF 译文随翻译进度显示；其他格式的阅读预览在暂停或完成时更新，减少长文档的重复处理。

字幕选择 **仅译文** 时会替换字幕文字，保留序号、时间轴和格式标签；选择 **双语对照** 则在同一时间段内保留原文与译文。校订会写入下载文件。尚未完成时，需要明确确认下载当前结果，缺少译文或已清空译文的位置保留原文。更改设置不会自动重译，下载仍使用当前保留的结果。

::: tip 离开前记得下载
翻译和校订结果保留在当前页面。刷新、关闭或打开其他文件之前，请先下载需要的结果。
:::

## PDF 有哪些限制？

在线和本地导入的 PDF 共用阅读器。原页文字可以选择、复制，并按你的划词设置显示翻译图标、直接弹出卡片或使用快捷键；划词使用设置中的划词翻译服务，整篇翻译使用文档翻译服务。可连续阅读、输入页码跳转或调整缩放，无需先翻译整份文件。

阅读器优先渲染可见页，最多保留五页的画布与文字层，离屏页会释放并在返回时重新生成。缩放保留当前页位置；导入显示下载字节或解析页数，并支持取消后重试。

请使用可以选中文字的 PDF。扫描版 PDF 暂不支持直接识别，可先用其他工具识别成文字文档，或对少量页面使用图片翻译。

PDF 默认使用 **清晰阅读**：译文按完整段落排版，正文保持可读字号，翻译过程中即可阅读和复制。公式、表格和插图保留原图；正文按栏和章节顺序组织，复杂版面仍需对照原页核对。也可以切换 **原版面** 查看位置对照，页面下方保留完整译文，长译文不会被挤成小字或裁掉。

下载 PDF 时，清晰译文以固定字号自动续页，双语版保留原论文页并接上对应译文页。选择原版面时，下载还会包含位置预览。下载中的中文译页仍以图像呈现，不能直接复制；可在阅读器中复制译文。生成进度按原稿页数显示，全部页面处理完后进入保存阶段，可以点击 **取消生成**；当前译文和校订会保留，可以再次下载。阅读器只保留附近页面，导出逐页编码并释放画布，控制长文档的内存占用。

## 文件会上传吗？

文件在浏览器中解析，待译文字会发送给你选择的翻译服务。使用云端翻译时，相关文字会离开本机；详见[数据与隐私](/guide/privacy)。

## 在 Obsidian 中翻译

FluentRead 提供[实验性 Obsidian 桌面插件](https://github.com/FluentRead/FluentRead/tree/main/integrations/obsidian)。按照插件目录中的说明构建并安装后，可从命令面板或文件右键菜单翻译 Markdown 笔记和带文字层的 PDF。译文会作为相邻的双语 Markdown 笔记保存并分栏打开，原文件不会被覆盖。Obsidian 插件目前使用微软翻译；待译文字会发送到该服务。PDF 译文按页排列，不保留原 PDF 版式。

## 批量翻译

可一次选择或拖入多个文件，也可在页面顶部点击 **添加文件**，保留已有文件和译文。多文件队列可收起，为阅读腾出空间。确认语言、翻译服务和模型后，点击 **翻译剩余文件**，按顺序处理尚未完成的文档。

每份文件独立显示进度。导入或翻译失败不影响其他文件；点击 **暂停全部** 保留已完成片段，再次开始时继续剩余内容。设置更改后，已有部分译文的文件需要逐份确认重新翻译，避免覆盖校订。

任务停止后，点击队列中的文件即可阅读、校订或单独下载。选择双语或仅译文，再点击 **下载已完成文件（ZIP）**，打包所有完成的文档；未完成的文件不包含在压缩包中。同名文件放在不同编号目录中。切换文件会保留当前结果，移除未下载的译文会先提示。

文件和译文仅保留在当前页面，刷新或关闭前请下载。
