# 支持 FluentRead

FluentRead 是一个开源项目，其持续开发离不开社区的慷慨支持。 项目采用 GPL-3.0 许可证。感谢您通过反馈、贡献代码、完善文档或赞赏，支持项目的开发与维护。

<SupportOptions />

如需参与项目开发，请访问 [GitHub](https://github.com/FluentRead/FluentRead)；使用中遇到问题，可以[提交反馈](https://github.com/FluentRead/FluentRead/issues)。

扩展设置的“关于流畅阅读”页面上方展示简介、版本和“官方网站”入口；点击即可在新标签页打开 [FluentRead 官网](https://read.thinkstu.com)。下方的“了解更多”集中提供文档、源码和反馈入口，“支持 FluentRead”提供紧凑的微信赞赏码与 Ko-fi 链接。点击赞赏码可打开原图。点击设置页左上角的品牌图标或名称，也可以打开官网。
