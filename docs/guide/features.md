# 网页与划词翻译

FluentRead 支持网页全文双语对照、划词翻译和悬浮翻译，译文在当前网页中显示。

## 页面翻译

扩展菜单顶部的“流畅阅读”下方显示当前安装版本号。

打开扩展菜单，点击“翻译页面”。默认将原文与译文按段落排列，保留标题、链接和正文结构，方便随时核对。阅读论文或 Codeforces 题面时，文字周围的常见公式也会尽量保留原来的显示。Codeforces 比赛卡片中的状态、名称和注册链接分别翻译，实时倒计时仅保留原站点的一份，秒数变化不会反复重建译文。

默认按阅读位置逐步翻译；如果需要一次处理整页，可在全文翻译设置中调整范围。点击“恢复原文”即可移除译文，之后可以换语言或服务再次翻译。

页面出现需要先处理的公告或模态弹窗时，全文翻译会优先处理当前弹窗，等你关闭后自动继续原页面。翻译途中出现公告也会暂停尚未完成的正文任务，保留已经显示的译文。开启翻译进度提示时，等待期间会显示“关闭弹窗后自动继续翻译”；点击“恢复原文”会同时取消自动续译。普通提示条和非阻塞面板不会让全文翻译一直等待。

将 FluentRead 固定到浏览器工具栏后，图标右下角会显示小而半透明的三角折角提示：蓝色时钟表示正在翻译，绿色对勾表示当前已进入翻译的内容完成，橙色感叹号表示有内容翻译失败，可以在页面中点击“重试”。默认随阅读位置翻译时，尚未滚动到的内容会稍后处理。恢复原文、关闭翻译或刷新页面后，图标恢复原样。

### 补充翻译菜单和动态界面

某些网站的菜单、按钮或导航文字没有被翻译时，可在 **设置 → 高级选项 → 页面识别** 中开启 **识别全部节点**。先恢复原文，再重新翻译。此选项会保存，也会处理翻译期间新展开的可见菜单。

识别范围更大时，页面里的操作文字也可能发生变化。不需要时关闭，下一次翻译恢复默认范围。图片、图表里无法选中的文字，请使用[图片翻译](/guide/image-translation)或[圈选翻译](/guide/area-translation)。

## 选中即译

先在扩展菜单的 **划词翻译** 中开启双语显示，再选中词语、句子或段落，点击附近的 FluentRead 图标查看译文。含行内公式的句子也可以选中翻译，卡片原文会将公式整理为一份文本表示。卡片可以复制结果和朗读原文。窗口挡住原文时，可以按住顶部或内容周围的空白处拖动；拖动任意边缘或四角可以调整宽高，文字会随宽度自动换行，长内容可在卡片内滚动。调整会保留到本次卡片关闭，重新划词时恢复默认大小并靠近新选区显示。读完后关闭即可。点击网页其他按钮或按 Escape 会关闭卡片；网页保留旧选区时也不会再次弹出。

喜欢更直接的操作，可以在划词设置中改成直接弹出、按键触发或其他手势，并调整出现前的等待时间。只需要查意思时，使用普通翻译服务即可。

## 悬浮翻译

将鼠标停在想读的段落上，按 **Control** 翻译当前段落。不必拖动选择，也不必翻译整页。快捷键和触发方式都能修改，详见[快捷键与触发方式](/guide/custom-hotkey)。

## AI 翻译卡与学习中心

[翻译卡](/guide/deepseek-harness)可以讲解语气、拆分长句、介绍表达用法，或围绕原文生成练习。它需要连接 AI 服务，只有点击动作后才发起请求。

遇到想记住的单词、短语或句子，可以收藏到[学习中心](/guide/vocabulary-book)，结合原句练习和复习。

## 图片、文件与字幕

- [图片翻译](/guide/image-translation)：识别图片文字，在原图上查看译文。
- [圈选翻译](/guide/area-translation)：圈出画面中的一小块文字，得到可复制的译文。
- [文档翻译](/guide/document-translation)：导入文件，对照阅读、校订并下载。
- [视频字幕](/guide/video-subtitles)：在 YouTube 与 X 视频里显示双语字幕。

## 多种翻译服务

免费翻译可以直接开始。已有 DeepL、AI 服务账号或本地 Ollama 模型时，也可以按[服务配置指南](/config/translation-engines)使用自己的服务。AI 翻译可配合[术语库](/guide/glossary)统一专业词汇。

## 自动翻译与网站规则

经常阅读同一个网站，可以让它自动翻译；希望某个网站保持原样，也可以单独关闭。正文漏译时先看[网站阅读范围](/config/site-adaptation)，无需从编写规则开始。

## 恢复、样式和主题

在[设置](/config/)中选择译文显示样式、界面主题和菜单栏布局。不常用的入口可以隐藏，常用的放在手边。隐藏入口不会删除收藏或停用对应功能。


### 请求限制

在「高级选项 → 请求限制」中调整翻译并发数、每秒和每分钟最多请求数。默认值分别为 **6**、**10** 和 **250**；已有设置会保留。每秒或每分钟的数值设为 **0** 表示不限制该项。

未单独配置的服务和模型共用全局限制。需要适配某个 API 的额度时，进入「翻译服务」，展开页面底部的「高级设置」，关闭「跟随全局设置」即可为当前模型填写限制。切换模型后可以分别设置。

如果一个服务的所有模型共用额度，点击「服务请求限制」设置服务总上限。单独配置的模型同时受该服务总上限约束；未配置的模型直接使用服务限制。重新开启「跟随」会恢复继承，并保留之前填写的数值，方便以后再次使用。

达到上限的请求会排队等待。失败后的重试次数与重试间隔在全局高级选项中统一设置。

## 更多翻译语言

源语言和目标语言现在提供 52 个语言选项，包括简体中文、繁体中文、德语、葡萄牙语、意大利语、阿拉伯语、印地语、越南语、泰语、乌克兰语和斯瓦希里语等。输入框翻译与写作助手也使用同一份语言列表；源语言仍可选择自动检测。原有语言设置会保留。

选择语言后，使用支持该语言对的翻译服务。不同机器翻译服务、AI 模型和 Chrome 内置翻译的语言范围不同；语言出现在列表中不代表每项服务都支持。图片文字识别和视频语音识别仍取决于各自的识别语言包或模型。

DeepL 当前不支持卡纳达语和僧伽罗语，选择这些语言时会提示切换服务。谷歌、小牛的挪威语以及微软的塞尔维亚语会自动转换为对应接口的语言代码；无需手动修改。
