# 功能介绍

FluentRead 的功能都围绕一个目标：让你在当前页面完成理解，不必在网页、翻译器和词典之间来回切换。

## 页面翻译

点击“翻译页面”，译文会放在原文附近，形成可以对照阅读的双语页面。原文不会被覆盖，随时可以恢复。

阅读论文时，双语译文会保留原文中的行内公式，包括原生 MathML、KaTeX、MathJax 和 Wikipedia 公式图片。公式沿用网页的渲染结构，周围文字正常翻译；恢复原文和再次翻译不会改写原始公式。

## 选中即译

选中句子、段落或术语，就能打开聚焦的翻译卡片。它适合快速确认意思、查一个单词或核对专有名词，不需要等待整页处理。

还可以根据习惯使用悬浮、双击、长按、中键和触屏手势等方式触发翻译。具体触发方式可以在[设置](/config/)中调整。

## 图片、文件与字幕

### 图片翻译

图片翻译适合截图、漫画、扫描资料和网页图片。FluentRead 会先识别图片中的文字，再使用你选择的翻译服务生成译文。图片越清晰、背景越简单，结果通常越稳定。详情见[图片翻译](/guide/image-translation)。

### 文档翻译

文档翻译适合不想复制粘贴的本地文件。当前支持 PDF、ePub、HTML、JSON、TXT、DOCX、Markdown，以及 SRT、VTT、ASS、SSA、LRC 等字幕文件。文件会在浏览器中读取和整理，完成后可以预览并导出结果。

### YouTube 字幕翻译

开启视频字幕功能后，FluentRead 会翻译 YouTube 已提供的字幕文本，并显示原文与译文。它不上传音频，也不会凭空生成没有字幕的视频内容；视频字幕功能目前仍属于 Beta。

## 多种翻译服务

你可以根据阅读场景选择服务：

| 需求 | 可以先尝试 |
| --- | --- |
| 想马上开始 | 免费翻译服务 |
| 想要稳定的通用翻译 | Microsoft、Google 或 DeepL |
| 需要上下文和风格 | OpenAI 兼容 API 或其他 AI 服务 |
| 希望内容留在本机 | Ollama 本地模型 |

服务的价格、额度和数据政策由服务提供方决定，配置方法见[翻译服务](/config/translation-engines)。

## 自动翻译与网站规则

可以让常用网站自动翻译，也可以对某个网站关闭 FluentRead。规则按网站保存，适合固定阅读新闻、文档或社区网站。需要时可以在[设置](/config/)中修改。

## 恢复、样式和主题

译文不会永久覆盖原文。你可以恢复当前页面，换目标语言或服务后再次翻译；也可以选择译文样式、浅色或深色主题，让页面更适合长时间阅读。

### YouTube / X 视频字幕翻译（Beta 测试）
视频字幕翻译默认关闭。在 YouTube 播放器或 X status 视频播放器旁会显示 FluentRead 图标入口。YouTube / X 已提供原生字幕时，FluentRead 会复用字幕轨道或页面已经渲染的字幕文本，在播放器中显示双语译文；不改变视频时间轴。字幕菜单支持“双语 / 仅译文 / 仅原文”、独立的“显示字幕”和“下载字幕”。

X 没有原生字幕时，可以在播放器菜单中点击“生成 AI 字幕”。生成入口与字幕显示控制分组排列，生成时显示进度并可停止，就绪后可关闭 AI 字幕；底部并排提供原文和译文字幕下载。菜单右上角显示当前翻译服务，点击可打开视频设置。

弹窗视频设置中的“X 视频 · 本地 AI”独立分组提供模型选择和下载入口，与通用翻译服务和字号设置分隔。先在视频设置下载 Tiny 或 Base 本地模型；推荐先用速度更快、占用较低的 Tiny。下载完成后回到播放器即可生成，无需刷新页面；如果模型状态暂时读取失败，菜单会提示重试。模型首次下载需要联网，下载完成后识别音频留在浏览器本地；字幕文字仍会交给你选择的翻译服务生成译文，不需要 Python、Docker 或额外本地服务。

只有点击后才会读取音频。扩展优先读取当前视频的独立音轨，完成识别和译文准备后，按当前播放位置显示字幕。生成过程保留你的视频播放或暂停状态、播放位置、倍速与音量；跳转时不会把之前那句字幕移到新位置。明显停顿会用于校准字幕边界；持续低背景音与语音可明确区分时，也会估计底噪后再定位停顿。完整识别结束后会统一重叠窗口的时间边界，播放和导出的 SRT 使用同一条时间轴。再次点击可停止生成，离开当前视频会取消相关请求。

本地 AI 识别目前需要桌面 Chrome/Edge 的扩展离屏能力。独立音轨无法读取时会尝试单独的扫描副本，因此可能需要更久；不支持的媒体格式会显示失败状态，可重试或使用原生字幕。单次完整识别支持最长 20 分钟的视频，耗时与视频长度、电脑性能、模型和翻译服务有关。

视频翻译服务与网页文本翻译服务独立配置，可以在“通用设置”或弹窗的视频字幕卡片中选择字幕译文服务、本地 Whisper 模型和字幕字号。原生字幕的完整 cue 会提前预取并缓存；如果站点只给出逐词或局部文本，则回退到稳定后实时翻译。完整设置中的“视频字幕 Beta 测试”页面可以关闭该功能；当前处理 YouTube 的 `/watch`、`/shorts` 和 X / Twitter 的 `/status/` 视频页。

在“基础配置 → 界面布局”中，“界面与弹窗”提供 14 套皮肤：默认、简约、紧凑、高对比、奶酪、海盐、抹茶、樱花、Emoji 乐园、夜幕、纸张护眼、极光舷窗、像素街机和落日公路。海盐、抹茶与樱花使用更明亮的色彩和水波、叶片、花瓣背景，Emoji 乐园带来奶油纸与彩色贴纸；极光舷窗、像素街机与落日公路分别加入光带、像素网格和夕阳公路图案，并兼容深浅模式。

同页的“菜单栏布局”提供“整体区域”和“快捷入口”两个视图。直接拖动左侧预览中的区域或快捷卡片即可调整顺序，也可以在右侧“已显示”列表中拖动整张卡片或使用方向键；不常用的入口用“隐藏”移到下方，之后可从“已隐藏”区域点“添加”恢复。布局会自动保存；所有皮肤（包括完整默认布局）的菜单栏都会随实际内容自适应高度，隐藏栏目或卡片后自动收缩，底部不保留多余空白。这些设置只影响入口展示，不会停用对应能力。

## 单词本 Beta

选中一个英文单词后，可以把它收藏到本地单词本，之后再复习。单词本不需要账号，也不会上传学习记录；它目前只支持单个英文单词，更多说明见[单词本 Beta](/guide/vocabulary-book)。
