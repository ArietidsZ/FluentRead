# 数据与隐私

FluentRead 没有账号体系，也没有自己的翻译服务器。你使用什么功能、选择什么服务，决定了哪些内容会离开浏览器。

## 会发送什么？

| 你使用的功能 | 可能发送的内容 | 接收方 |
| --- | --- | --- |
| 页面、划词和视频字幕翻译 | 需要翻译的文字、源语言和目标语言；部分 AI 服务可能使用页面标题或上下文 | 你当前选择的翻译服务 |
| 免费翻译 | 需要翻译的文字 | 免费翻译链中的第三方服务 |
| AI 智能上下文 | 生成上下文摘要所需的页面标题、描述和部分正文；此功能默认关闭 | 你当前选择的 AI 服务 |
| 图片与圈选翻译 | 图片中识别出的文字 | 你当前选择的翻译服务 |
| 单词学习卡 | 你主动选中的单词，以及生成译文所需的信息 | 公共词典服务和当前翻译服务 |
| DeepSeek Harness 阅读理解 | 你点击阅读动作后提交的选中文本；启用上下文时还包括按设置裁剪的授权段落和短会话问题 | 你在 Harness 中选择的 AI 服务 |
| 朗读 | 你主动朗读的文字和语言 | 对应的语音服务 |

输入框翻译只处理你主动提交的普通文本输入框内容，不读取密码框。

## 什么会留在本机？

- 普通设置、网站规则、翻译缓存和单词本保存在当前浏览器的扩展私有存储中。
- API Key 和其他凭据保存在扩展的本地受保护存储中，不会发送到 FluentRead 自己的服务器。
- 油猴脚本的设置保存在脚本管理器提供的私有存储中。
- 配置备份可能包含凭据和你主动收藏的阅读上下文；导出或分享前请先检查文件内容。

在 **完整设置 → 高级选项 → 翻译缓存** 中，可以查看缓存的估算容量和存储条数、刷新用量或清空缓存。打开“调整缓存上限”可分别设置容量（1–100 MiB）和条数（100–50,000 条），默认最多 **5 MiB / 2,000 条**，达到任一上限就会自动腾出空间。调小上限会立即清理超额记录：先删除过期项，再淘汰最久未使用的结果（LRU）。记录最长保留 24 小时，命中不会延长有效期；单条超过 256 KiB 的结果不会缓存。

网页全文、悬浮等译文共用此缓存。卡片同时给出大约可缓存的结果数量和页数：有缓存时按现有结果的平均大小计算，无缓存时按每条 1 KiB 参考值计算，再按每页 50 条折算。它不是完整网页快照数量，实际容量会随文本长度、服务和内容而变化。

容量按缓存键和译文的 UTF-8 大小估算，不包含浏览器的索引、数据库页等内部开销，因此不等于浏览器报告的实际磁盘占用。关闭缓存后不再读写已有翻译缓存，仍可在此查看和清空。

清除翻译缓存不会删除单词本。卸载扩展或清除浏览器数据可能会删除本地设置和学习记录。

## 如何减少内容出站？

1. 选择本地 Ollama 或浏览器内置翻译，减少对云端服务的依赖。
2. 不需要时关闭 AI 智能上下文。
3. 只翻译选中的句子，而不是整页发送。
4. DeepSeek Harness 默认只在你点击阅读动作后发送选中文本；需要时再开启段落上下文。
5. 使用云端服务前，阅读服务商自己的隐私政策、额度和数据保留说明。
6. 不要在共享设备上填写 API Key；怀疑泄露时立即撤销并重新生成。

FluentRead 不会因为你打开网页就自动把整页内容发送出去；只有触发对应功能并选择了服务后，相关请求才会发出。
