# 数据与隐私

你选择的功能和服务，决定哪些内容会发送出去。FluentRead 没有自建翻译服务器；云端翻译由对应的第三方服务处理。

## 使用功能时，会发送什么？

| 功能 | 发送的内容与去向 |
| --- | --- |
| 网页、悬浮、划词、输入框翻译 | 待译文字和语言信息，发送给所选翻译服务 |
| 免费翻译服务 | 待译文字；自动均衡会由后台根据成功率、响应耗时和近期错误分配给已启用的服务，失败后可能发送给其他候选 |
| AI 精翻 | 额外参考的网页标题、描述和部分正文，发送给当前 AI 服务；默认关闭 |
| 翻译卡片与学习讲解 | 主动提交的词句、允许参考的原文、必要问答，以及启用且被使用的学习记忆，发送给所选 AI 服务 |
| 术语库 | 本次原文实际命中的词语与指定译法，随支持术语的 AI 请求发送；不会发送整份词库 |
| 图片翻译、本地 OCR 圈选 | 图片在本地识别，识别出的文字发送给所选翻译服务 |
| 优先模型识图的圈选 | 开启且模型支持时，将裁剪后的选区图片发送给圈选服务识别，再发送识别文字进行翻译；不上传整屏截图 |
| 文档翻译 | 文件在浏览器中解析，待译文字发送给所选翻译服务 |
| 视频字幕 | 字幕文字发送给字幕翻译服务；X 本地 AI 的音频识别在本机完成 |
| 查词与朗读 | 主动查询或朗读的文字，发送给对应词典或语音服务 |
| Google Drive 配置同步（Chrome） | 用户主动确认后，将完整配置的本机加密密文保存到该用户 Google Drive 的隐藏应用数据区；配置包含 API Key、OAuth Token、鉴权头、自定义请求体和 URL 鉴权参数 |

图片语言包和本地 AI 模型首次准备需要联网下载。输入框翻译默认关闭，只处理你主动触发翻译的输入内容，不读取密码框。

英文词卡随扩展提供常用词库。查询未收录的单词时，扩展可从 JSDMirror、GitHub Raw 或 jsDelivr 下载约 3.9 MB 的固定版本完整词库并缓存；该静态文件请求不包含所查单词。在线词典仍可能按上表向对应服务发送单词。

开启自动翻译的网站，会在符合设置的页面自动发起翻译请求。仅选择本地翻译模型，并不意味着词典、朗读、模型下载等独立功能也全部离线。

## 哪些内容留在浏览器里？

- 设置、网站规则、术语、收藏与复习记录保存在当前浏览器的扩展存储中。
- 免费翻译的健康、错误和性能统计保存在当前浏览器的本地存储中，仅用于后台自动分配和冷却恢复。
- API 密钥等凭据保存在扩展本地凭据存储中，用于连接对应服务。能访问浏览器配置或备份文件的人仍可能读取相关内容。
- 普通模式的翻译卡片问答保留 30 天，可以查看和删除。隐私窗口不保存也不读取该历史，也不提供持久学习收藏。
- 翻译缓存暂存已完成的结果，默认最多 5 MiB 或 2,000 条，记录最长保留 24 小时；可在设置中调整或清空。
- 按需下载的完整英文词库保存在浏览器的 CacheStorage 中；清除浏览器站点数据或卸载扩展会移除它。
- X 已识别视频的字幕文字与时间可缓存最多 32 个视频、7 天，不保存识别音频；可在视频设置中清除。
- 文档翻译与校订结果留在当前页面，关闭前请下载需要的文件。

## 怎么控制这些数据？

Google Drive 同步需要主动连接账号并确认操作，用户无需输入口令。扩展自动使用固定应用口令 `FluentReadEncryption`，在本机加密完整配置后上传；另一设备连接同一个 Google 账号即可恢复。云端文件不包含单词本、聊天记录或用量统计。固定口令随开源代码公开，拿到密文的人可以解密；云端访问保护主要依赖 Google 账号和应用授权。请保护账号、设备与云端文件。

断开同步连接会清除扩展的身份缓存，保留云端文件和本机配置。如需彻底撤销许可，请在 Google 账号的第三方连接中移除 FluentRead；如需删除隐藏数据，可在 Google Drive 网页的设置 → 管理应用中删除 FluentRead 的应用数据。删除云端数据不会删除其他设备已下载的设置。

不需要的自动翻译、AI 精翻、学习记忆和收藏入口可以关闭。翻译卡片的原文范围可改为“当前选区”，减少发送的上下文。

清除翻译缓存不会删除学习收藏。收藏、阅读记录和学习记忆请在各自页面管理。卸载扩展或清除浏览器数据可能删除这些本地记录。

备份可能包含密钥、原句和来源信息；导出前确认范围，分享前检查内容。使用云端服务时，请按服务商自己的政策了解其数据保存方式。
