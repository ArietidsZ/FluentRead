# 数据与隐私

FluentRead 没有账号体系，也没有自己的翻译服务器。你使用什么功能、选择什么服务，决定了哪些内容会离开浏览器。

## 会发送什么？

| 你使用的功能 | 可能发送的内容 | 接收方 |
| --- | --- | --- |
| 页面、划词和视频字幕翻译 | 需要翻译的文字、源语言和目标语言；部分 AI 服务可能使用页面标题或上下文 | 你当前选择的翻译服务 |
| 免费翻译 | 需要翻译的文字 | 免费翻译链中的第三方服务 |
| AI 智能上下文 | 生成上下文摘要所需的页面标题、描述和部分正文；此功能默认关闭 | 你当前选择的 AI 服务 |
| 图片与圈选翻译 | 图片中识别出的文字 | 你当前选择的翻译服务 |
| 单词学习卡 | 你主动选中的单词，以及生成译文所需的信息 | 公共词典服务和当前翻译服务 |
| 朗读 | 你主动朗读的文字和语言 | 对应的语音服务 |

输入框翻译只处理你主动提交的普通文本输入框内容，不读取密码框。

## 什么会留在本机？

- 普通设置、网站规则、翻译缓存和单词本保存在当前浏览器的扩展私有存储中。
- API Key 和其他凭据保存在扩展的本地受保护存储中，不会发送到 FluentRead 自己的服务器。
- 油猴脚本的设置保存在脚本管理器提供的私有存储中。
- 配置备份可能包含凭据和你主动收藏的阅读上下文；导出或分享前请先检查文件内容。

清除翻译缓存不会删除单词本。卸载扩展或清除浏览器数据可能会删除本地设置和学习记录。

## 如何减少内容出站？

1. 选择本地 Ollama 或浏览器内置翻译，减少对云端服务的依赖。
2. 不需要时关闭 AI 智能上下文。
3. 只翻译选中的句子，而不是整页发送。
4. 使用云端服务前，阅读服务商自己的隐私政策、额度和数据保留说明。
5. 不要在共享设备上填写 API Key；怀疑泄露时立即撤销并重新生成。

FluentRead 不会因为你打开网页就自动把整页内容发送出去；只有触发对应功能并选择了服务后，相关请求才会发出。
