# 信息高亮

信息高亮在正文中标出值得留意的词语，帮助浏览长段落。原文仍完整可读，选取、复制和排版保持原样。当前入口位于设置，网页默认关闭。

## 使用

1. 打开 **设置 → 翻译设置 → 阅读辅助 → 信息高亮**。
2. 选择模式、密度、颜色和绘制方式，通过示意预览查看外观。
3. 在 FluentRead PDF 阅读器工具栏开启 **信息高亮**，应用于当前文档；关闭即可清除标记。

选择本地模型模式时，模型状态和下载按钮紧跟模式选择；模型不可用时，可明确点击 **使用关键词模式**。设置内的预览是外观示例，不是模型分析结果。

颜色、密度和模式保存在设置中。修改偏好或下载模型不会自动开启网页高亮，Popup 中没有信息高亮入口。


在 FluentRead PDF 阅读器中，可从工具栏开启 **信息高亮**。它使用现有可选文字层，原页图像和布局保持原样；没有文字层的扫描页不参与分析。

## 两种模式

| 模式 | 适合什么 | 处理方式 |
| --- | --- | --- |
| 关键词 | 快速浏览主题词语 | 轻量本地算法，无需下载模型 |
| 信息意外度 | 留意上下文中不容易预测的词语 | FluentRead 按需下载 Qwen，在设备上计算预测概率 |

两种模式都在本机处理正文。下载模型会访问模型托管站点；评分不会向其发送网页文字。

信息意外度使用 `−log₂ P(词语 | 前文)`。分数高表示模型较难预测该词，不代表它更重要、更正确，也不验证文章事实。名称、罕见词、错字等都可能获得高分；阅读时仍需留意未高亮的否定和条件。

## 外观与性能

提供少、适中、多三档密度，以及琥珀、薄荷、蓝色配色。可选择柔和底色或细下划线。调整密度和外观会复用已有评分，无需重新分析。

这里的“本地模型”由 FluentRead 下载并运行，不依赖 Edge、Firefox 或其他浏览器内置的 AI。当前使用 Qwen2.5 0.5B，首次下载约 490 MB；扩展通过 ONNX Runtime Web 在独立 Worker 中调用设备的 WebGPU 计算，下载完成后可离线分析。

首次使用需点击下载操作。模型模式需要浏览器和设备提供受支持的 WebGPU 能力；页面或模型不可用时会显示原因，可以手动改用关键词模式。正文不会自动上传到云端。

下载暂停或中断后，已保存的部分会保留，可以继续下载。文件校验、存储空间或模型启动错误会显示对应恢复提示；已有完整模型文件时，重试不会重新下载文件。

长页面优先处理阅读位置附近的文字。快速滚动时推迟分析，关闭后取消当前任务并丢弃迟到结果。页面正文更新后重新分析对应内容。代码、编辑器、表单和公式等区域不参与正文高亮。

需要浏览器支持 CSS Custom Highlight API；没有该能力时会保留正常页面并显示不支持状态。
