# 常见问题

## 点击“翻译页面”后没有变化

先确认当前是普通网页，并且页面中有可见文字。浏览器内部页面、扩展商店和部分受保护的编辑器通常不允许扩展工作。

如果页面正常，请检查目标语言和翻译服务。可以先选中一句话测试服务，再尝试整页翻译。

## 页面只翻译了一部分

长页面可能正在分批处理，也可能受到页面动态加载、服务额度或请求速度影响。等待页面加载完成后重试；仍不完整时，可以先恢复原文，再分段翻译。

## QQ 邮箱的邮件正文可以翻译吗？

浏览器扩展支持新版与旧版 QQ 邮箱的邮件阅读页。打开邮件后，可以使用“翻译页面”，或把鼠标放在正文上按已配置的悬停翻译快捷键。

旧版邮箱的邮件正文会跟随页面一起翻译和恢复；全文翻译开启时，切换打开的邮件会继续翻译。编辑中的草稿和标记为不翻译的内容会保留原文。

## 如何恢复原文？

打开 FluentRead 弹窗，点击“恢复原文”。这只会移除 FluentRead 添加的译文，不会删除网页本身的内容。

如果更换了目标语言或翻译服务，建议先恢复原文，再重新翻译。

## 为什么选区翻译可以用，整页翻译却不行？

选区翻译只处理你选中的文字，整页翻译还需要识别页面结构并跳过导航、按钮等内容。遇到特殊网页时，可以先使用选区翻译。

## Ollama 无法连接

确认 Ollama 已在本机运行、模型已经安装，并且 FluentRead 中的地址与本机地址一致。若仍然失败，请在设置中重新检查连接。

## API Key 应该放在哪里？

只填写在 FluentRead 的服务设置中。不要把 API Key 放进网页、截图、Issue、聊天记录或 Git 仓库。如果已经泄露，请立即在服务商控制台撤销并重新生成。

## 翻译结果重复或排版异常

先恢复原文并刷新页面，再重新翻译。对于会不断加载内容的网站，等页面稳定后再操作；同时确认没有运行其他网页翻译扩展。

## 仍然无法解决？

可以在 [GitHub Issues](https://github.com/FluentRead/FluentRead/issues) 反馈浏览器、FluentRead 版本、网页类型和复现步骤。提交前请删除 API Key、Cookie、个人信息和受保护的原文。
