# DeepSeek Harness

FluentRead 的 DeepSeek Harness 是一个贴着选区使用的阅读理解工具。它适合在网页阅读时快速弄清一句话的意思、句子结构和表达用法，也可以继续追问或把单词加入单词本。

## 开始使用

打开扩展设置，进入 **工具与学习 > DeepSeek Harness**，开启功能并选择服务和模型。它会复用 FluentRead 已保存的翻译服务凭据；服务列表中的模型由对应服务支持，Claude 和 Gemini 使用各自的原生模型协议，其他接入按服务的兼容协议发送。

在网页中双击单词，或拖动选中一句话。选区旁直接显示你已启用的“读懂”“拆句”“用法”和“练习”，优先动作以主样式显示。点击对应动作后开始分析，也可以在卡片中切换动作。只完成选区不会自动调用模型。首次使用时如果没有可用服务、模型或凭据，卡片会提示你去设置页补全配置。

设置页提供可点击的例句卡片：切换动作就能看到相应的回答示例，示例不调用模型。服务和模型直接显示；动作偏好、上下文范围、解释深度和学习程度放在“更多设置”中。隐藏一个动作后，示例与网页工具条会同步隐藏它。

单词选区可以在回答后显式加入单词本。加入单词本由你主动点击完成，阅读助手本身没有写入网页或其他外部数据的权限。

## 阅读方式

- **读懂**：说明原意，并解释语气、指代或隐含含义。
- **拆句**：先给出句子主干，再说明从句、修饰关系和关键语法。
- **用法**：挑出值得学习的表达，说明搭配、语气和自然例句。
- **练习**：围绕当前内容生成一道小练习，帮助迁移使用。

双击通常只会选中一个单词。卡片提供“理解整句”时，点击它才会将分析对象扩展为这个单词所在的整句。上下文范围是独立设置：默认允许模型通过只读工具使用当前段落；选择“当前选区”则只发送选中文字。

普通模式下每条问答在本机保存 30 天。选区旁点击“记录”，或在阅读卡中点击“阅读记录”，即可查看原文摘要、动作、日期和轮次。选择一条后恢复原文与回答，展开“前面的问答”可阅读更早内容，也可以直接继续追问。打开或恢复记录不产生模型请求；“返回当前阅读”回到原卡片。设置页通过“查看记录”进入列表，点击记录可查看独立详情，支持删除和清空。

真实追问最多使用最近 4 轮有回答的问答，中断回答会明确标为未完成。点击读懂、拆句等动作时则独立分析当前原文，不把旧回答当成继续聊天的指令；这些分析仍保存在同一条阅读记录里。

保留期限按每条问答的创建时间计算，继续会话不会延长旧问答的期限。扩展启动、定期清理和读取历史时会删除过期问答，空会话一并移除。

回答随模型正文增量实时显示，网络片段不一定恰好一个字。卡片固定在可视区域内，长回答在内部滚动，逐步生成和追问不会因正文高度改变而重新选择上下位置。回答及历史共用 Markdown 展示，支持标题、列表、强调、代码、引用和简单表格。卡片支持停止、重试和复制；停止或错误时已收到的正文会保留并标示状态。模型服务返回的用量会以“阅读理解”用途记录在本机模型用量中；用量记录只保存服务、模型、时间、结果和可用的 Token 数，不保存选中文本、段落、回答或 API Key。

## 数据范围

点击学习动作时，扩展会捕获选中文字；默认的“可参考本段”模式还会捕获并裁剪所在正文段落，交给后台的只读 `read_context` 工具。模型只能通过这个工具取得已捕获的段落，不能继续读取页面其他内容。“仅选中文字”模式不提供段落工具。整句候选在点击“理解整句”前留在页面本地。

阅读卡只在当前选区生命周期内工作。页面导航、选区变化、关闭卡片、切换设置或扩展卸载时，未完成请求会被取消，迟到的回答不会写回新的选区。后台重启后，中断的会话会标为已停止，并保留此前已保存的部分正文。隐私窗口不保存也不读取历史。

## 开发者边界

完整的模块取舍、代码位置及 Mermaid 架构图保存在仓库 `docs/reports/harness-embedding-map-20260905.md`。该地图以 PR #440 的已提交内核为核查基线，说明哪些规则来自上游、哪些由 FluentRead 实现；开发报告目录不发布到文档站点。

FluentRead 参考 DeepSeek Harness `dsh-v0.1.3-alpha.1`，固定 commit 为 [`d347e703908d0406b7a7ef80e3a0e594d86b2215`](https://github.com/deepseek-ai/deepseek-harness/tree/d347e703908d0406b7a7ef80e3a0e594d86b2215)。参考文件是 [`packages/core/session/src/surface.ts`](https://github.com/deepseek-ai/deepseek-harness/blob/d347e703908d0406b7a7ef80e3a0e594d86b2215/packages/core/session/src/surface.ts)，已审阅文件 SHA-256 为 `aa75a34df001b33d3b1e4dd5c24a0391d00bc457e0a83f25757d3358b12b684f`。

本地实现只采用 surface 的 append-only 投影子集：保留 surface 类型、append marker、连续序号校验、用户/助手/工具消息投影和只追加 ledger。它没有逐行复制完整上游，也没有实现 replacement 或 provenance rewrite；本地会话按问答在本机保存 30 天并支持删除/清空，循环是独立的有界实现，另行限制模型调用次数、工具调用次数、请求时限、重复工具 ID 和取消行为。

扩展不包含 DeepSeek Harness 的 CLI、桌面 Web UI、host/bridge、Cordis 插件加载器、文件系统、shell、子进程、沙箱、动态代码执行、远程插件或网页抓取能力。模型通过 FluentRead 的 AI SDK gateway 选择，支持兼容服务和原生 Anthropic/Google 服务，需要模型支持工具调用才能使用段落工具；不支持时可以选择“当前选区”模式。阅读卡通过 runtime stream port 增量显示模型正文。
