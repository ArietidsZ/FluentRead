# 自定义快捷键

如果你经常翻译页面或恢复原文，可以给 FluentRead 设置快捷键，不打开弹窗也能快速操作。

## 设置步骤

### Chrome 或 Edge

1. 打开浏览器的扩展管理页。
2. 进入“键盘快捷键”或“扩展快捷键”。
3. 找到 FluentRead，点击对应操作的输入框。
4. 按下新的组合键并保存。

### Firefox

从 Firefox 的附加组件管理页进入扩展快捷键设置，具体入口名称会随浏览器版本略有不同。

## 怎么选快捷键？

建议选择不容易与网页冲突的组合，例如 Ctrl/Cmd + Shift + L。不要使用浏览器、输入法或操作系统已经占用的组合键。

快捷键没有反应时，先确认当前不是浏览器内部页面或扩展商店，再用弹窗按钮确认 FluentRead 本身可以正常翻译。
