# 图片翻译

图片翻译适合截图、漫画、扫描资料和网页图片中的文字。FluentRead 会先识别图片文字，再使用你选择的翻译服务生成译文。

## 适合什么内容？

- 截图中的按钮、菜单和提示；
- 漫画气泡或海报；
- 扫描资料和图片型文档；
- 网页中无法直接选中的图片文字。

## 开始前

1. 在设置中启用图片翻译，首次使用时按提示准备 OCR 语言包。
2. 确认至少有一个可用的翻译服务。
3. 尽量使用清晰、完整、对比度高的图片。

## 如何使用？

打开包含图片的网页，在 FluentRead 弹窗中进入图片翻译。根据页面提示选择目标图片或圈选区域，等待识别和翻译完成即可。

图片翻译通常比普通文本需要更多时间。结果出现后，请重点核对人名、数字、表格和专有名词。

## 结果不准确怎么办？

- 换用更清晰的原图，或先裁掉无关背景；
- 放大图片后再识别；
- 对竖排文字、艺术字体和复杂表格手动核对；
- 仍然不理想时，直接选中页面上的文字进行翻译。

图片文字会按照当前服务的请求规则处理。敏感图片更适合使用本地模型，或不要上传到第三方服务。
