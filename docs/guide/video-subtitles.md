# 视频字幕

在 YouTube 和 X 视频中一起看原字幕与译文，也可以只显示一种语言。

扩展菜单中的 **视频字幕** 面板可以快速开关翻译、切换 **双语 / 仅译文 / 仅原文**。翻译服务、字幕外观和本地 AI 模型集中在底部的 **视频翻译设置** 中，修改后自动保存。

X 播放器自动收起控制栏时，已打开的字幕菜单会保持显示；开关、显示模式和 AI 字幕状态会随操作更新，方便连续调整。点击菜单外部或按 Esc 可关闭菜单。

## 已有字幕的视频

1. 确认 FluentRead 的 **视频字幕翻译** 已开启。
2. 打开 YouTube 或 X 视频，找到播放器控制栏最右侧的 FluentRead 图标。
3. 打开字幕菜单，选择 **双语 / 仅译文 / 仅原文**。

字幕来自视频已有的字幕轨道或网页显示的字幕。没有可用字幕时，不能保证直接生成译文。字幕翻译服务可以在视频设置中单独选择，不必与网页翻译相同。

YouTube 全屏时也可以打开播放器字幕菜单。双语字幕会作为一组显示；换句、字幕空档或拖动进度时会清除上一句译文。尚未翻译好的句子先显示原文，译文完成后仅在对应句子仍有效时补上。

## X 视频没有字幕时

桌面 Chrome / Edge 扩展可以尝试本地 AI 字幕：

1. 在视频设置的本地 AI 模型卡片中选择并下载模型。通常先用 **Tiny**，需要尝试更完整的识别时可选 **Base**。Tiny 下载约 100 MB，Base 约 150 MB，后续可能补充运行文件。
2. 回到 X 播放器，点击 **生成 AI 字幕**。
3. 等待识别与翻译完成；生成过程中可以停止。

本地识别会优先使用可用的 GPU 加速；浏览器不支持或加速失败时自动改用 CPU，无需手动切换。

音频识别在本机进行，识别出的字幕文字仍交给所选翻译服务。首次下载需要网络，生成时间取决于视频长度和电脑性能。目前单段视频最长支持 20 分钟；部分媒体格式或受限制的视频无法读取。

## 调整显示和保存字幕

在视频字幕外观设置中修改字号、背景、位置和显示宽度。X 字幕按视频实际画面定位，竖屏视频中的长字幕会在画面内换行；调整播放器大小或切换全屏时会同步更新位置，播放控件出现时会尽量避让。

菜单中可单独开关字幕显示、下载字幕。X 已完整识别的字幕会在本机缓存一段时间，重复打开同一视频通常无需重新识别。缓存命中后立即恢复字幕时间轴，译文逐步显示；返回视频设置时会刷新缓存数量。需要重新开始时，使用 **重新识别字幕** 或清除视频缓存。

## 没有字幕或时间不准

先确认视频本身有字幕，再尝试打开原生字幕。若使用 X 本地 AI 识别，检查模型是否下载完成，必要时明确指定视频原语言。

识别可能听错人名、专有名词或背景音，译文也可能有误。重要细节请结合音频和原字幕核对。
