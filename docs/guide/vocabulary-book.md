# 单词本 Beta

阅读中遇到一个重要的英文单词时，可以把它收藏下来，之后再复习。单词本不需要账号，学习记录保存在当前浏览器中。

## 开启与收藏

1. 打开完整设置，进入“单词本”并开启功能。
2. 在网页中选中一个英文单词。
3. 等划词卡片出现后，点击星标即可收藏。

目前单词本只支持单个英文单词，不支持短语、网址、数字或其他语言。再次点击星标可以更新阅读上下文。

## 复习

单词本会把词条分为待复习、学习中、熟悉和已掌握。复习时先回想单词含义，再选择“忘了”或“记得”，帮助自己逐步巩固。

## 数据与隐私

词条和复习记录只保存在本机，不会上传，也不会被清除翻译缓存删除。只有主动收藏时，才会保存少量阅读上下文；可以在备份前选择是否包含这些内容。

卸载扩展或清除浏览器数据可能会删除单词本。更换浏览器前，请先在“备份与恢复”中导出数据。

## Beta 边界

当前版本不包含云同步、账号、多个词本、标签、AI 自动出题或 Anki 双向同步；它更适合作为阅读过程中的轻量收藏和复习工具。
